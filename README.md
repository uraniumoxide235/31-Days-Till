# 31 Days till

A Godot game built by [uraniumoxide235](https://github.com/uraniumoxide235).

## 📥 How to Play

1. Head over to the **Releases** section on the right side of this GitHub page.
2. Download the ZIP file for your operating system.
3. Unzip/extract the archive anywhere on your computer.
4. Run the executable (`.exe`) file to play!

---

## 🛠️ Building / Source Code
If you want to view, modify, or build the game yourself from the source code:
* Requires **Godot Engine 4.7** (or compatible 4.x versions).
* Open the `project.godot` file inside the Godot editor.
